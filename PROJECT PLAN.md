# ProxiSpeak - Geospatial Audio Platform

## Problem
People visit places but don't know the story/history. Text boards boring.

## Solution
ProxiSpeak - When user goes near a location (within 100m), audio story automatically plays. Like Pokemon Go but for stories.

## Tech Stack
- Frontend: React + Leaflet Maps
- Backend: Firebase (Auth + Firestore + Storage)
- Audio: Web Audio API
- Hosting: Vercel

## Architecture
User -> Opens Map -> Sees Audio Markers -> Walks near Marker (100m) -> Audio Auto Plays -> User can Like/Save
